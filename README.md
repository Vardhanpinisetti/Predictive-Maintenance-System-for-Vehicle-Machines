# Predictive Maintenance System using Machine Learning

This project predicts whether a machine will fail based on sensor data using ML models such as Random Forest and XGBoost. It uses the AI4I 2020 Industrial IoT dataset.

## Features Used
- Temperature
- Torque
- Rotational speed
- Tool wear

## Techniques Applied
✔ Data Cleaning  
✔ Encoding  
✔ Scaling  
✔ Train-Test Split  
✔ SMOTE balancing  
✔ Model Comparison  
✔ Deployment using joblib  

## Results

Best Model: Random Forest/XGBoost  
Accuracy: 'Logistic Regression': 0.999, 'Random Forest': 0.9985, 'XGBoost': 0.9975'
